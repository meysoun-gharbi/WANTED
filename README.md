# WANTED — LPWAN Wireless Security Testbed

## Project Overview

This project focuses on the implementation and experimental evaluation of wireless attacks targeting **Low-Power Wide-Area Networks (LPWAN)**, particularly LoRaWAN communications.

The objective is to reproduce attack scenarios identified in scientific literature, evaluate their behavior under controlled conditions, and integrate the resulting implementations into the **WANTED (Wireless Attack Network Testbed for Embedded Devices)** platform.

All experiments are conducted in an isolated, authorized test environment.

## Project Objectives

- Study wireless security threats affecting LPWAN and LoRaWAN communications.
- Identify relevant attack scenarios from scientific publications.
- Implement selected attacks using embedded hardware and software tools.
- Experimentally test and analyze the implemented scenarios in an isolated testbed.
- Contribute attack implementations and technical documentation to the WANTED platform.

## Technical Environment

**Technologies:** LoRaWAN, LPWAN, embedded systems, wireless communication protocols, Arduino, Linux.

**Experimental approach:** Literature review, attack implementation, controlled experimentation, and analysis of observed results.

## Repository Structure

- `lorawan/` — LoRaWAN-related implementations, experiments, and attack scenarios.
- `lorawan/attaques/` — Implementations of selected attack scenarios.
- `lorawan/sniffing/` — Wireless traffic observation and sniffing tools.
- `comptes_rendus/` — Technical reports, experimental documentation, and project deliverables.

## Methodology

1. **Literature review:** Identify and analyze LPWAN attack scenarios described in scientific publications.
2. **Scenario selection:** Select attacks relevant to the experimental platform and available equipment.
3. **Implementation:** Develop or adapt the necessary software and embedded components.
4. **Experimental validation:** Execute the scenarios in an isolated and controlled environment.
5. **Integration:** Organize and document the implementations for integration into the WANTED testbed.

## Research and Educational Context

This project is conducted in an academic embedded systems cybersecurity context at **Université Bretagne Sud (France)**.

The work contributes to the study and experimental evaluation of wireless security threats affecting embedded and IoT systems.

## Ethical Considerations

The implementations are intended exclusively for authorized cybersecurity research and educational experimentation. Testing must be limited to controlled environments and devices for which explicit authorization has been granted.
